Home Menu

An Enterprise-style home menu for Odoo Community

After login, and whenever no action is open, the web client shows a full-screen grid of application tiles instead of the first app. The top-left navbar button brings the home menu back on top of the current action, and back again.

  • Arrow keys move between the apps, Enter opens the focused one.
  • Escape returns to the action behind the home menu.
  • Typing any character searches apps and menus in the command palette.
  • On small screens, the "All Apps" button of the app sidebar opens the home menu.
